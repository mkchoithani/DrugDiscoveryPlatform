Design–Make–Test loop

A working model of the closed-loop medicinal-chemistry cycle: enumerate a library that is synthesisable by construction, score it against competing drug-like properties, plan routes that share intermediates, then let an uncertainty-aware model choose each next batch. The assay is a simulated ground truth, so you can see how close the loop gets to the best compound in the library.
